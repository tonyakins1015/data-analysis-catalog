표준 양식 규격

머리글 7개 컬럼을 그대로 사용합니다. 컬럼명이 다르면 업로드되지 않으며, 값은 임의로 채우지 않습니다.

  1. 지역 — 전국 또는 시도 정식명칭(예: 경기도, 서울특별시, 전남광주통합특별시)
  2. 데이터구분 — 인구지표 / 지역내총생산 / 경제활동인구 / 자동차등록 / 대중교통접근시간 / 작업환경
  3. 항목 — 데이터구분별 지표명 (예: 총인구(명), 지역내총생산(시장가격), 고용률, 총계, 5분미만, 산업분류명)
  4. 세부항목 — 필요한 구분값만 사용 (GRDP: 명목/실질/실질기여도 · 자동차: 계 · 작업환경: 유해요인). 없으면 공백
  5. 기준시점 — 연도(2024) 또는 연월(2026.07) 또는 잠정 표기(2024(잠정))
  6. 값 — 숫자만. 결측은 행 자체를 넣지 않습니다
  7. 단위 — 명 / 백만원 / %p / 천명 / % / 대 / 개소 / 세 / 지수

지역별로 나눈 파일을 여러 개 동시에 올릴 수 있으며, 업로드한 지역만 지도·비교차트에서 활성화됩니다. 인구 중위추계·산업별 작업환경은 원자료가 전국 단위로만 공표되므로 지역 파일에는 포함되지 않고, 전국 통합 파일을 올려야 해당 패널이 활성화됩니다.
